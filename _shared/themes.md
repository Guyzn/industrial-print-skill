# 多专业主题色板（Themes）· 9 套预设

9 套「简洁教育 × 瑞士风」低饱和预设色板（第 9 套朱砂为模版 C 东方学报风专属）。**只许选，不许自定义 hex**——颜色搭配错了画面瞬间变丑，保护美学比给自由更重要。

---

## 使用方法

1. 问用户选哪套（或按专业推荐一套）
2. 打开模板（`<专业>-职业发展手册.html`）的 `<style>` 块
3. 找到开头 `:root` 里标有「SLOT: theme tokens」的变量块
4. **整体替换**这 13 个变量：`--bg / --surface / --fg / --muted / --border / --accent / --accent-2 / --warn / --marker` + 封面专属 `--cov-ink / --cov-year / --cov-mist / --cov-line`
5. 其他 CSS 全走 `var(--...)`，无需其他改动

**封面学院蓝全主题化**：封面主色走 `--cov-ink`、2026 大年份 SVG 走 `--cov-year`（内联 `fill="currentColor"`，`color:var(--cov-year)`）、封底下缘色带走 `--cov-mist`、红色装饰线走 `--cov-line`。**换主题只改这 13 个 token，封面代码本身一行不动**——版式永不漂移。

**硬规则**：
- 一份手册只用一套主题，不要中途换色
- 不要接受用户给的任意 hex——委婉拒绝并展示 9 套让选
- 不要混搭（如 bg 取学院蓝、accent 取勃艮第红）——会彻底违和

## 印刷色准说明（送印必读）

- 浏览器「另存为 PDF」全程是 **sRGB**；印刷机是 **CMYK**。RGB→CMYK 必然有转换，**绝对「不偏色」不存在**。
- 本 skill 的色板全部落在 **CMYK 安全域**内（背景高明度低饱和、正文近黑、accent 低饱和深色系），保证偏色趋近于零且可控可复现。
- 每套色板下方附 **CMYK 换算表**：走商业印刷时，直接按 C/M/Y/K 值做分色，不经浏览器转换——这是印刷品色准的行业标准做法。
- 送印前请在 PDF 里做**软打样**（soft-proof，按 FOGRA39 / US Web Coated 预览）确认。
- 如实告知：办公室打印机 + 普通纸必有目视色差（不受代码控制）；要色准，走商业印刷 + 标准 ICC。
