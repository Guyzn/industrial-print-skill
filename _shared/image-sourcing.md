# 图片来源与授权规则

> 适用于所有模版（A/B/C/D/E）。E（企业介绍/作品集）用得最多，但规则不分模版。
> 一句话：**先解决像素，再解决授权，两样都过才放进版面。**

## 一、来源优先级

从高到低。能用上一档就不要用下一档：

| 档 | 来源 | 说明 |
|---|---|---|
| 1 | 客户提供的原始拍摄文件 | 相机直出或 RAW 转 TIFF/JPG，长边 ≥ 3000px。最佳 |
| 2 | 客户官网的**原图** | 注意不是网页上渲染的那张。WordPress 常见 `xxx-300x182.jpg` 是缩略图，去掉尺寸后缀往往能拿到原图 |
| 3 | 委托拍摄 | 明确约定版权归客户，合同留档 |
| 4 | 正版图库（已购授权） | 保留授权凭证与订单号，记录在 `sources.md` |
| ✘ | 竞品官网、行业门户、百度图片、带水印图库 | **禁止**。不是「找不到就用」，是根本不能用 |

## 二、分辨率：唯一硬指标

印刷 300ppi，公式：

```
可印宽度(mm) = 像素宽 ÷ 300 × 25.4
所需像素宽   = 目标宽度(mm) ÷ 25.4 × 300
```

常用尺寸的最小像素（300ppi）：

| 版面用途 | 宽度 | 最小像素宽 |
|---|---|---|
| **跨对开（E 的 spread 页型）** | **426mm** | **5031px** |
| A4 整幅出血图 | 216mm | 2551px |
| A4 通栏（版心 176mm） | 176mm | 2079px |
| 半栏（85mm） | 85mm | 1004px |
| 三栏图（56mm） | 56mm | 661px |
| 小图 / 缩略（40mm） | 40mm | 472px |

跨对开是全书最经不起虚的位置：一张 3000px 的图铺满 426mm 只有 179ppi，在 157g 铜版纸上会明显发软。宁可把跨页换成单页通栏，也不要硬拉。

判定口径：

- **≥300ppi**：可用于任何位置。
- **200–300ppi**：可用于半栏及以下；整幅会出现细节软。
- **150–200ppi**：只能做小图，且不要与高质量图并排（对比会露馅）。
- **<150ppi**：不用。宁可留白或换构图。

网页图的典型值：1200px 宽 ≈ 在 176mm 下只有 173ppi。**「网页上看着清楚」和「印出来清楚」是两件事**，屏幕 72–96ppi 就够，印刷要 300。

## 三、抓图脚本

```bash
# 只看候选，不下载
node scripts/fetch-images.mjs https://example.com/products --dry-run

# 下载（同域 + robots + 尺寸过滤 + 登记来源）
node scripts/fetch-images.mjs https://example.com/products \
  --out ./content/images --limit 30 --min-width 1200 --print-width 176
```

产物：

- `images/img-<hash>.<ext>` —— 内容哈希命名，重复抓不会产生副本
- `images/manifest.json` —— 每张图的来源页、原始 URL、像素、`ppi_at_print_width`、`max_print_width_at_300ppi_mm`、`ok_for_print`
- `images/sources.md` —— 给客户看的来源清单，**授权列默认空白，必须人工填**

脚本写死的边界（不要改）：

1. 只抓同域 + `--allow` 白名单，不外扩；
2. 先读 `robots.txt`，命中 Disallow 直接退出码 3；
3. 不抓 `logo/icon/sprite/avatar`（`--include-logo` 可放开）；
4. 低于 `--min-width` 跳过并计数，不做「先下下来再说」；
5. 不绕登录、不破防盗链、不抓水印图。

## 四、官网原图的常见陷阱

- **WordPress 缩略图**：`photo-300x182.jpg` / `photo-768x465.jpg` 都是派生尺寸。原图通常是同目录下不带后缀的 `photo.jpg`。先试这个，再考虑抓。
- **Elementor / 页面构建器的 thumbs 目录**：`/uploads/elementor/thumbs/xxx.jpg` 一定是缩略图，原图在 `/uploads/YYYY/MM/xxx.jpg`。
- **WebP 压缩**：很多站点把原图转成 WebP 并降质。要印刷就找 JPG/PNG 原图，或让客户给原始文件。
- **CDN 裁剪参数**：`?w=800`、`?quality=70` 这类参数去掉往往能拿原图。脚本按 URL 抓，不会自动试参数——需要人工判断。
- **响应式 `<picture>`**：`srcset` 里最大那项通常仍是压缩过的，别把它当原图。

## 五、授权登记（P0，缺一项不许送印）

每张进入版面的图，在 `sources.md` 里必须有四列完整：

| 列 | 内容 |
|---|---|
| 文件 | `img-xxxxxxxx.jpg` |
| 来源 | 原始 URL 或「客户提供 / 拍摄合同编号」 |
| 授权 | 自有 / 已购（订单号）/ 客户授权（邮件日期）/ **待确认** |
| 限制 | 仅限本次印刷 / 地区限制 / 期限 |

红线：

1. **带水印的图一律不用**，裁掉水印也算违规。
2. **图库里出现的他人产品、他人厂房、他人商标**，即使图是客户给的，也要确认是否获得被摄方许可。
3. **人物肖像**：可辨识的个人需肖像权授权，尤其是客户合影、员工特写。
4. **客户 logo / 商标**出现在图里，需要有业务关系证明（供货合同即可）。
5. **AI 生成图**：不要冒充实景。用作气氛图要在图注注明，不能放在「我们的厂房」这种位置。

## 六、缺图时的正确做法

按优先级：

1. 找客户要原图（写明用途与最小像素，一次要齐）；
2. 用现有高质量图重新构图（裁切、留白、局部放大）；
3. 缩小图片在版面上的宽度（从整幅改成半栏）；
4. 改成文字 + 表格 + 数字带，把版面做实；
5. 留白，但要用版式手法收住（见 E 的托底图规则）——**不要用低质量图填坑**。

反面做法（禁止）：拉伸放大、锐化硬撑、网上随便找图、用竞品照片、把缩略图当原图。
