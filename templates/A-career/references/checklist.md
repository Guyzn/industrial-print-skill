# Checklist · 交付前自检（每次生成手册后必跑）

> 两条线：**自动检查**（跑 `scripts/validate-handbook.mjs`，会输出缺项）与**人工检查**（逐条过一遍，尤其印刷相关的 4 项）。

---

## 0. 自动检查（必跑）

```bash
node ~/.claude/skills/career-handbook-skill/scripts/validate-handbook.mjs <手册.html>
```

通过标准：
- `data-layout` 覆盖率 100%（每个 `.page` 都有）
- 所有 `id="sp-*"` 都被目录锚点引用（无死锚点）
- 每个 `.bar-fill` 的 `--v` 有对应的 `.bar-value` 数值标签；`--max` 非 0
- 每个 `.donut` 的 `--d0`/`--d1` 有配套图例 `.lg-*`
- 无外链图片 URL（`http(s)://` 图片 src）
- 无空 `<figure>`、无空 `alt`
- 每个 `.page` 都含 `.page-foot` 且 `.pf-num` 非空
- **封面若仍是占位校徽（`logo-placeholder.svg`）→ 正式交付/送印前必须替换为真实校徽**（本镜像可分享，但不得带着占位符当成品交付）

---

## 1. 数据正确性（P0，影响信任）

- [ ] 图表数值与源文档 §2.3 完全一致（百分比、岗位数、城市档位、学历、经验）
- [ ] 每根条 `.bar-value` = 真实数值，`.bar-label > small` 附了绝对量
- [ ] 环形图角度按「百分比 × 3.6°」累加计算，非肉眼估
- [ ] 目录页码与正文 `.pf-num` 一一对应
- [ ] 岗位 12 段式序号连续（01–12），每页从段序连续起头

## 2. 版式与出血（P1）

- [ ] 页边距：内容 ≥ 8mm 至裁切、≥ 12mm 至书脊
- [ ] 每页主体不跨页、不贴 `.page-foot`
- [ ] 溢出检查：无元素溢出 `.page` 边界（表格 `table-layout:fixed`，长文拆页）
- [ ] 封面/幕封全出血图 opacity ≤ 0.16，文字可读
- [ ] **第一部分每页有页头**（纯数据页 `.data-run` 文字在上分割线下；带图页 `.dp-hero-full` 兼作页头；band 首页 `.dp-title` 兼作页头）——除幕封外无一页裸秃
- [ ] **第一部分模块间距 12mm**（`.dp-module { margin-top:12mm }`，页首模块加 `.no-gap`）
- [ ] **第一部分图解块一律「上文后图表」堆叠**，无左图右文/两栏平铺
- [ ] **唯一分页约束 = 内容底部距页码分割线留白 ∈ [6,14]mm**：每页内容底面到 `.page-foot` 上缘留白落在此带内；内容放不下「能放多少放多少」、余下续排换页，仅图表原子化放不下整表换页；触 6mm 下限才换页、>14mm 回拉（`PULL_LEEWAY=14`）。**页数无奇数/偶数、幕封无「落左页」硬约束**，完全由实际内容撑出。
- [ ] **图表/柱状图多色相**：`.bar-fill` 用 `var(--bar)`（`--c1/--c2/--c3` 轮换），非单一 accent

## 3. 字体与印刷（P1，送印最重）

- [ ] **字体已本地嵌入**：MiSans @font-face 用本地 `assets/fonts/`，不走 CDN（PDF 才能内嵌）
- [ ] PDF 导出 300dpi；导出后抽查「封面大字、`.st-num`、`.js-nb`」是否缺字形（缺则换系统 CJK 栈）
- [ ] 主题色全部来自 themes.md 9 套之一（无手搓 hex）
- [ ] **学院蓝全主题化**：封面 `--cov-ink/--cov-year/--cov-mist/--cov-line` 随主题切换，2026 大年份 SVG 走 `fill="currentColor"`（`color:var(--cov-year)`），换主题不手改封面代码
- [ ] 商业印刷时按 themes.md CMYK 表分色 + 软打样 FOGRA39 校对
- [ ] 办公室打印需用 `.no-bleed` 类（精确 420×285）

## 4. 内容完整性（P2）

- [ ] 封面信息完整（专业名、学校、年份）
- [ ] 目录可跳转（锚点命中），点开每个锚点无 404
- [ ] 图注齐全（`.fig-note`）；每张图有描述性 `alt`
- [ ] 岗位信息：准入学历、核心方向、薪酬表（如适用）、职业路径齐全

## 5. 一致性（P3）

- [ ] 全部 `.page` 有 `data-layout`；骨架用模板类名，无自造类
- [ ] 中文标点全角、数字半角；禁止竖排
- [ ] 两份手册（不同专业）对比：版式完全一致，只差内容与主题色
