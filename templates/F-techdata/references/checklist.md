# F · 技术数据表送印前人审清单

> `validate.mjs` 只能证明**机械合格**（尺寸、页码、裁切标记、字体路径、表格列数、数据身份标注完整性）。
> 下面这些它看不出来，必须人看。**P0 任一项存疑即停，不许送印。**

## P0 · 不通过就不能下印

### 数据真实性（TDS 的生死线）

- [ ] **技术数据与正式技术文件一致**——成分、力学、热处理窗口不是凭记忆写的；每个数字能指出出处。
- [ ] **数据身份标注完整**：每张含数值的表都标了 `basis`（spec/typical/min/max/range）；工序表、对策表标 `basis:"none"`。不能只标一部分——读者会把没标的当成保证值。
- [ ] **典型值都有试验条件出处**：`meta.test_conditions` 登记、表上 `cond` 引用；cond 里的温度/保温与实际测试口径一致。
- [ ] **按 `references/grade-datasheet.md` 的 L0–L6 骨架自查**：牌号身份→标准对应→成分→性能→热处理→检验→免责依据，一层不缺。
- [ ] **免责与验收口径写了**：「典型值不构成验收依据」或等效声明在文件里出现（概述页/封底），外文版同样要有。
- [ ] **没有编造价格或性能**；没有核价来源的字段一律删。

### 版式与印刷

- [ ] **占位图全部替换**：搜索 `ph-` / `placeholder`，一张都不能留。
- [ ] **文字没有溢出或被裁**：逐页看 PDF——密表页最容易超高，标题不被盖、末行不压页脚。密表页必须 `valign:"top"`。
- [ ] **中英文没有半吊子**：`lang: bi` 时每个表头、分组行、图注都有英文；`lang: en` 时页面无中文残留；纯数字/单位列两种模式下都在。
- [ ] **表格列宽合理**：长文本列（介质/对策/说明）有显式 `w`，折行正常，不顶穿相邻列。
- [ ] **公司主体一致**：页眉品牌、封面、封底、联系信息四处同一法人主体；信用证项下照 LC 原文抄。
- [ ] **PDF 里没有系统字体**：`pdffonts x.pdf` 只许见 MiSans / IBMPlexMono 等 bundled 子集；出现 Arial / NSimSun / PingFangSC / Menlo 即回退。内联 SVG 图（曲线图）的字也要查——这正是 svg 块存在的理由。
- [ ] **TrimBox 与裁切标记在**：`pdfinfo` 尺寸 216×303；跑过 `_shared/pdf_print_marks.py` 后 TrimBox 210×297。
- [ ] **页数偶数**（封面+封底计入），封底不编页。

## P1 · 影响观感，应该改

- [ ] 每页页尾不留大洞（>40mm）：加 `spacer` 或提下一张表上来，不许压字号。
- [ ] 一页一个主体：「成分+性能+热处理挤一页」→ 拆页。
- [ ] 牌号概述页横幅字段齐全：牌号、系列、各国标准对照（AISI/DIN/GB/JIS 有的都写）。
- [ ] 数值列都标了 `num: true`（右对齐）；分组行标签中英双语。
- [ ] 目录页码与正文一致（改页序后重新构建，不手改 HTML）。
- [ ] 曲线图数据点有来源记录（实测/标准附图重绘），不是随手画的。

## P2 · 锦上添花

- [ ] 文档编号、版本号、修订记录随文件控制台账管理；封底「文件控制」信息与台账一致。
- [ ] 内容 JSON 已存档（进 git 或知识库），改稿可追溯。
- [ ] 交付附一句口径说明：「本文件为印刷成品，PDF 由 HTML 直接导出，成品 210×297mm、含出血 216×303mm，TrimBox/BleedBox 与裁切标记已嵌入」。

## 常见翻车点（都是踩过的）

| 现象 | 原因 | 处置 |
|---|---|---|
| 密表页标题被白块吃掉一半 | 内容略高 + `v-center` 把溢出平分向上下 | 密表页一律 `valign:"top"`；仍超高就减行/压 padding/拆页 |
| 末行压页脚 | 表行数 × padding 超预算 | proc 表 padding 已压到 1.2mm；再超就拆页 |
| 客户拿典型值验收 | basis 只标了一部分表 | 标全；说明性表标 `none` |
| 两页同一参数两套数 | 试验条件各表各写 | `meta.test_conditions` 登记 + `cond` 引用 |
| 曲线图字体与正文不一 | `<img>` 引 SVG 拿不到页面字体 | 用 `svg` 块内联 |
| 英文稿数字列消失 | 旧模版把纯 ASCII 单元格当中文隐藏 | F 已修（isNeutral 直出），见到即升版 |
| 单元格「碳Carbon」粘连 | 中英写进一个字符串 | 用 `{zh,en}` 对象 |
