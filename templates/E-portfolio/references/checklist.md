# E · 送印前人审清单

> `validate.mjs` 只能证明**机械合格**（尺寸、页码、裁切标记、字体路径、表格列数）。
> 下面这些它看不出来，必须人看。**P0 任一项存疑即停，不许送印。**

## P0 · 不通过就不能下印

- [ ] **占位图全部替换**。搜索 `ph-` / `placeholder`，一张都不能留；封面、章节页、牌号页托底图逐页确认。
- [ ] **图片来源清单已填完**。`images/sources.md` 的「授权」列没有空白行；每张图能说出出处。
- [ ] **图片分辨率达标**。整幅 ≥300ppi，半栏 ≥250ppi，小图 ≥200ppi；`manifest.json` 里 `ok_for_print` 为 false 的不得用于整幅。
- [ ] **文字没有溢出或被裁**。逐页看 PDF：标题不压图、表格不出血线、页脚不被裁切标记切到。
- [ ] **中英文没有半吊子**。`lang: bi` 时每个标题、每个表格头、每个图注都有英文；`lang: en` 时页面上不出现中文残留。
- [ ] **品牌名与主体一致**。页眉品牌、封面法定名、页脚、联系页四处写的必须是同一个法人主体，不能一处母公司一处子公司。
- [ ] **价格 / 技术数据有出处**。成分、力学、热处理窗口与正式技术文件一致；价格字段经内部核价，未核价的一律删。
- [ ] **PDF 里没有系统字体**。`pdffonts x.pdf` 只许见 MiSans / IBMPlexMono / NotoSerifSC 等；出现 Arial、NSimSun、PingFangSC、Menlo 即回退。
- [ ] **TrimBox 与裁切标记在**。`pdfinfo` 看尺寸应是 216×303；跑过 `pdf_print_marks.py` 后 TrimBox 应为 210×297。

## P1 · 影响观感，应该改

- [ ] **每页页尾不留大洞**。内容写完后剩余空白超过约 40mm 的页，加托底图、加 `spacer`，或用 `valign: distribute` 把余量摊进块间。
- [ ] **标题没被竖向分配拖走**。`center` / `distribute` 只作用于正文块；标题应始终贴版心顶部。若标题漂到页面中部，检查是否误把标题写进了 `blocks`。
- [ ] **一页一个主体**。出现「两个牌号挤一页」「一页讲三件事」→ 拆页。
- [ ] **块间距一致**。同一页里不应出现 3mm 与 12mm 混排（除非是 spacer 有意为之）。
- [ ] **左边一条线干净**。小标题的橙色竖线悬挂在 12mm，正文与表格落在 17mm；不应出现两种缩进打架。
- [ ] **牌号页字段齐全**。对照表、成分、物理、力学、热处理、供货形式、应用，七项缺一不可（缺的项如果没有数据，写「按订单」而不是留空）。
- [ ] **对照表首列是行标题**。浅底、左对齐、加粗，否则读者会在网格里迷路。
- [ ] **数字带不超过 4 格**。5 格以上在 A4 宽度下每格小于 33mm，数字会挤。
- [ ] **图注统一**。全部「图 1 / Figure 1」或全部无编号，不要一半有一半没有。
- [ ] **目录页码与正文一致**。改过页序后必须重新构建，不要手改 HTML。

## P2 · 锦上添花

- [ ] **跨页图片方向一致**。左右页的照片色温、明暗接近，不要一页冷灰一页荧光。
- [ ] **图集网格图高统一**。`c3` 是 52mm、`c2` 是 60mm，同一页不要混用。
- [ ] **章节页有导语**。只有标题的章节页会显得单薄，加一句 lede 或一张图。
- [ ] **联系页有行动指令**。写「发图纸给我们，两个工作日内报价」，比只列邮箱有效。
- [ ] **封面 slogan 与品牌规范一致**。品牌换了口号，旧册子的句子不要留。

## 打印核对（出 PDF 后必做）

```bash
pdfinfo 企业介绍-送印.pdf | grep -E "Pages|Page size"      # 应为 216 × 303 mm
pdffonts 企业介绍-送印.pdf                                   # 只许见内置字体
python3 -c "d=open('企业介绍-送印.pdf','rb').read(); print('TrimBox', d.count(b'TrimBox'), 'BleedBox', d.count(b'BleedBox'))"
pdftoppm -png -r 150 企业介绍-送印.pdf page                   # 逐页看，别只看第一页
```

## 送回印厂前最后三问

1. **这份文件里有没有一页是「我自己都不确定它为什么长这样」的？** 有就翻回去看，通常那里有错。
2. **如果印厂按 TrimBox 裁，会不会切到字？** 所有文字离成品边至少 5mm。
3. **如果客户只翻三页就合上，翻到的是哪三页？** 那三页必须是全书最结实的。
