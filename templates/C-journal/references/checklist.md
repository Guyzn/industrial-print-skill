# Checklist · 交付前自检（模版 C · 东方学报风，每次生成后必跑）

> 两条线：**自动检查**（跑 `scripts/validate-journal.mjs`）与**人工检查**（逐条过一遍，尤其印刷相关的几项）。

---

## 0. 自动检查（必跑）

```bash
node <C-journal>/scripts/validate-journal.mjs <手册.html>
```

通过标准：
- `data-layout` 覆盖率 100%（X00–X18），页面 left/right 严格交替
- 页码奇偶与左右页一致（偶数在左页）、`.folio` 非空且递增；无 folio 白名单仅 X00/X01/X03/X15
- 目录 `.vt-entry` 的 `data-pg` 回填与显示页码一致
- SVG 内无 `fill="var(…)"`/`stroke="var(…)"`（必须 `style="stroke: var(--x);"`）
- 圆环图：viewBox `0 0 42 42`、首环 dashoffset=25、每环 dasharray 两值之和=100、有 `.donut-legend`
- 柱图柱数 = 标签数（含 acc 高亮柱）、峰值柱 height:100%；细条图宽 ≤ 100%
- 技能阶梯 `.ladder` 固定 3 级、序号「其一/其二/其三」连号、每级三件齐（t/k/d）
- 薪酬三档 `.sal` 固定 3 档（高级应有 acc 高亮）；发展路径每轨有箭头链与末级 `.hl`
- 岗位档案 `.jm-no` 序数连号（壹→拾贰），每岗位从壹起，十二段齐全
- 对开结构：spread 数 × 2 = 页面数；整版出血页（X01/X03/X15）padding:0
- 无残留 `[必填]` 占位符、无外链图片
- **封面若仍是占位校徽（`logo-placeholder.svg`）→ 正式交付/送印前必须替换为真实墨色单色校徽**（本镜像可分享，但不得带着占位符当成品交付）

---

## 1. 数据正确性（P0）

- [ ] 图表数值与源文档完全一致（占比、岗位数、城市、学历、经验、薪酬）
- [ ] 圆环图 <3% 的段按最小可视宽 2.3% 绘制，note 里注明
- [ ] 柱图柱高按占比等比、峰值柱 height:100%、`acc` 主峰唯一（朱砂柱）
- [ ] 细条图以最大值为满宽归一（最大项 100%）
- [ ] **目录与速览的页码指向对应页**，与成品 `.folio` 一一对应（build 自动回填，手改 HTML 会破坏）
- [ ] 引文文字忠于源文档，不夸大、不编造署名

## 2. 版式与出血（P1）

- [ ] 墨区：top 13 / outer 12 / fold 12 / bottom 26mm；folio 在 bottom 10mm
- [ ] **页面内容与页码至少 12mm 留白（铁律，最小值而非固定值）**——`.page` overflow:hidden 会静默裁切，必须几何校验
- [ ] 上篇六页固定顺序不可调（X08–X13）；每岗位固定 4 个详情页（X17a–X17d），不做贪心打包
- [ ] 幕封 X06 反白文字可读，出血纹理 opacity ≤ 0.16；整版出血图页（X01/X03/X15）删 folio
- [ ] 图注与图表成组 `.chart-unit`；正文 ≥ 9pt、图注 ≥ 7.5pt、mono 角标 ≥ 7pt
- [ ] 页面不得「内容贴底、中部留白」——模块下方间隙大就把下一模块接上来

## 3. 字体与印刷（P1）

- [ ] **字体本地嵌入**：标题/大数字 Noto Serif SC / 正文 MiSans / 角标页码 IBM Plex Mono，@font-face 走 `./fonts/` 相对路径（build 自动 cpSync）
- [ ] 主题色来自 `_shared/themes.md` 9 套之一；**朱砂 = 主题 `--accent`（C 唯一点缀色）**
- [ ] 墨色系只用 `--ink #1e1c17 / --ink-2 #3a372e / --muted #7d7666 / --border #d9d1bf`，绝无第三种强调色
- [ ] PDF 导出 300dpi；抽查封面大字、竖排 `.vt`、序数「壹贰叁」缺字形则换系统 CJK 栈
- [ ] 商业印刷按 themes.md CMYK 分色 + FOGRA39 软打样

## 4. 内容完整性（P2）

- [ ] 封面卷名/年份/统计条/印章齐全；序（X02）+ 序图（X03）成对
- [ ] 目录（X04/X05）与速览成对；幕封 X06 + 引文 X07 成对
- [ ] 上篇六章数据页各配一种图表（条图/圆环/大字格/细条/柱图/阶梯）且顺序固定
- [ ] 每岗位：封面 X15 + 详解 4 页（壹贰叁/肆伍陆/柒捌玖/拾拾壹/拾贰）+ 结语 X18，十二段齐全
- [ ] X18 结语含「拾贰·学习规划建议」sitem + 结语引文 + 下一篇预告

## 5. 一致性（P3）

- [ ] 全部 `.page` 有 `data-layout="Xxx"`；骨架用模板类名，无自造类
- [ ] 中文标点全角、数字半角；竖排仅限签名元素（印章 `.seal`、竖排 `.vt`、序数）
- [ ] 两份手册（不同专业）对比：版式完全一致，只差内容与主题色

## 送印前最后 30 秒

```
node scripts/build-journal.mjs content/<专业>.json dist/<专业>.html   # 重建
node scripts/validate-journal.mjs dist/<专业>.html                    # 自动
# 人工：封面印章 → 目录页码抽查 → 抽查 1 个数据页 → 抽查岗位结语页 → 送印 4 项
```
